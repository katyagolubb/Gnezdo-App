# Gnezdo-App

This repository combines two projects into a single structure for streamlined management:

- **user-management-api**: Contains the codebase from the original `Gnezdo` repository, focused on user management functionality.
- **book-api**: Contains the codebase from the original `book-management-api` repository, focused on book management functionality.

## Structure
- `user-management-api/`: Code for user-related features and API endpoints.
- `book-api/`: Code for book-related features and API endpoints.
